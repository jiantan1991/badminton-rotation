# 🏸 羽毛球双打轮转

微信打开即用的双打轮转小工具：输入 6 人强/弱名单 → 自动生成 3 场对阵
（每人恰好上场 2 次）→ 记分 → 积分排名 → 生成排名图发微信群。

## 在线访问

**https://jiantan1991.github.io/badminton-rotation/**（GitHub Pages，微信可直接打开）

## 使用

1. 打开页面，强组/弱组各填 2~4 人姓名（共 6 人），组内按实力从强到弱填
2. 自定义场数（3~30 的整数，默认 12；建议 3 的倍数保证每人场次一致），点"生成轮转表"
3. 按场次打完记分；全部打完自动出排名；可"生成排名图"长按保存发群
4. 数据保存在本机，重新打开页面自动恢复；"再来一局"开始新活动
5. 💾 设置页底部"数据备份"：打完可"复制备份文本"存到微信聊天/文件传输助手；
   数据丢失（微信清缓存/换手机）时，粘贴备份文本点"恢复数据"一键找回

## 两种使用方式

**① 单文件版 `badminton-single.html`**（推荐自用）：双击即可在浏览器打开，功能与多文件版完全一致。
修改代码后运行 `python build_single.py` 重新生成。

**② 多文件版**（项目根目录，便于部署与维护）：部署到服务器后微信内打开网址，数据保存更可靠。

## 部署（CentOS 7，一条命令）

```bash
cd /path/to/badminton-rotation
python3 -m http.server 8080 --bind 0.0.0.0
```

微信（同一网络）访问 `http://<服务器IP>:8080`。本地调试：`python -m http.server 8000` 后浏览器打开 `http://localhost:8000`。

## 说明

- 纯静态页面，无后端；数据存浏览器 localStorage（记录员手机），
  群友查看排名请用"生成排名图"分享
- 支持 3强3弱 / 2强4弱 / 4强2弱 三种人数分布；场数自定义（3~30，默认 12），
  每人上场次数完全一致（如 12 场时每人恰好 8 场），严格"打 2 休 1"节奏，
  每队优先 1强1弱，搭档/对阵尽量分散
